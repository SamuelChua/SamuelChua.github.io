## Aim

pill.ai explores how multimodal AI can help people check whether the medication they receive matches what was prescribed. The application combines a medication image with audio from a doctor–patient conversation, using Google's Gemini API to extract information for comparison.

## Approach

A dashboard presents the expected medications and verification alerts. The interface was built with React, Material UI, and JavaScript, with Gemini handling the image and conversation inputs.
